## Vue d'ensemble

Ce mois-ci, Smartbills présente des améliorations significatives à la boîte de réception par courriel et de nouvelles fonctionnalités pour les utilisateurs mobiles.

## Nouvelles fonctionnalités

### Boîte de réception

- Capture automatique des reçus par courriel pour les fournisseurs pris en charge
- Détection intelligente des pièces jointes de reçus
- Règles personnalisables pour le tri et l'attribution des dépenses

### Application mobile

- Mode hors ligne amélioré avec synchronisation différée
- Notifications push pour les approbations et les rejets
- Interface de numérisation optimisée pour une meilleure précision

## Améliorations

- Performances accrues du tableau de bord sur les grands ensembles de données
- Précision OCR améliorée pour les reçus thermiques
- Options d'export PDF avec logos personnalisés

<Warning>
Certaines anciennes API de webhooks seront dépréciées en mars 2025. Consultez la documentation pour migrer vers la nouvelle version.
</Warning>

## Corrections

- Correction des problèmes de synchronisation avec QuickBooks
- Résolution des erreurs d'affichage sur les écrans haute résolution
- Correction du délai de chargement des rapports volumineux
